# PythonIDE

Блочная Python-IDE для ПК. Форк редактора [TurboWarp](https://github.com/TurboWarp/scratch-gui):
блоки собираются в обычный Python-код, который можно сохранить файлом `.py` или запустить прямо из приложения.

## Что умеет

- Блоки Python (вывод и ввод, переменные, условия, циклы, функции, операторы, списки и словари, модули и время, свой код).
  В тулбоксе у каждой категории лежат все её блоки, а в категории «Все блоки» — абсолютно каждый блок подряд.
- Справа живое превью: **терминал**, если программа ничего не рисует, и **холст**, если рисует (блоки категории «Графика»).
- Ниже превью — сгенерированный Python-код.
- Запуск идёт настоящим Python на твоём компьютере, а не в браузере. Нужен установленный Python 3.
- Сохранение результата в `.py`, сохранение и открытие проектов (`.pyide`).
- Тёмная тема.

## Запуск

```
npm install
npm run app
```

`npm run app` собирает интерфейс и открывает окно приложения (Electron). Python ищется командами
`python3` / `python` (на Windows — `python` / `py -3`).

## Графика

Блоки графики используют модуль `pyide_gfx` (лежит в `electron/python`). Он печатает команды рисования
в stdout с особым префиксом, приложение их перехватывает и рисует на холсте. Весь остальной вывод идёт в терминал.
Окна tkinter, turtle или pygame в превью не встраиваются — они открываются своими окнами.

## Тесты

```
node --import ./test/register-hooks.mjs --disable-warning=MODULE_TYPELESS_PACKAGE_JSON --test test/py-generator.test.mjs test/py-session.test.mjs
```

Тесты генератора запускают получившийся код настоящим `python3`.
